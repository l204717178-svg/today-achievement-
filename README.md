# 今日成就

**把日常小事变成值得庆祝的隐藏成就。**

[在线体验「今日成就」](https://l204717178-svg.github.io/today-achievement-/)

## 产品介绍

「今日成就」是一款以生活小事为灵感的轻量游戏化 Web 产品。它邀请用户回头看看平凡的一天：一个人也认真吃了顿饭、收拾了一个小角落、说出了自己的需要，或者只是允许自己好好休息。这些没有人专门颁奖的时刻，都可以在这里成为一枚属于自己的生活奖章。

产品面向喜欢轻松互动、生活记录与个性化表达的年轻用户。睡前回顾一天、下班后想给自己一点鼓励，或想把一个小小的进步分享给朋友时，都可以打开它。不需要注册、写长篇日记或完成额外任务，从今天已经做过的事情中选择 1—3 项，就能开始发现自己的「隐藏成就」。

### 一次体验，会发生什么？

1. **回忆今天的小事**：在生活、自己、勇气、探索四类共 16 项行为中，选出今天做过的事情。行为卡先展示生活场景，把成就称号留到揭晓时再出现。
2. **揭晓专属奖章**：点击翻开成就卡，通过翻卡与短暂的彩纸动效，为普通的小事制造一点颁奖仪式感。每项行为都对应预设的称号、认可文案和趣味技能。
3. **收藏这份小骄傲**：已揭晓的成就进入当前浏览器里的「生活奖章馆」，记录首次发现日期。重复发现同一成就不会重复增加图鉴数量，用户可以按自己的节奏慢慢收集。
4. **带走一张纪念卡**：从本轮成就中挑选一枚，生成带有徽章、称号、文案和日期的分享图片。可以留给自己，也可以保存后分享到喜欢的平台。

例如，选择「允许自己好好休息」，会揭晓「休息特许官」：**“今天的暂停，不需要用忙碌来换取。”** 选择「拒绝了一个不想答应的请求」，则会获得「边界守护者」：**“这一次，你把自己的意愿也算了进去。”** 每枚奖章都围绕具体生活行为，给出一句轻松而温柔的回应。

### 我们希望带来的感受

- **被认可**：认真吃饭、放下手机发呆、表达需要，都值得被看见；成就不只属于忙碌和高产的一天。
- **有惊喜**：先选择行为，再揭晓隐藏称号，让回顾日常变成一次小小的发现。
- **有收藏的乐趣**：不同徽章与本地图鉴留下生活纪念，没有连续打卡或补签压力。
- **愿意表达**：精致的成就卡让用户用一张图片表达今天的心情与小骄傲，分享是选择，留给自己也很好。

视觉以温暖的奶油纸色为底，搭配珊瑚橙、薄荷绿与淡紫色，结合奖章、卡片和轻量动效，营造年轻、柔和的「生活奖章馆」氛围。界面优先适配手机，也支持桌面浏览；揭晓动画可以跳过，并适配系统的降低动态效果偏好。

R / SR / SSR 是预设的趣味卡面等级，不是随机抽卡概率，也不代表真实稀有度、人格评价或生活价值高低。所有行为与成就均通过固定内容映射，产品不会分析或判断用户。不同的生活方式，都同样值得庆祝。

## 实现概况

独立移动端 Web Demo，使用 HTML、CSS 和原生 JavaScript。运行时不调用 AI、后端或远程 API，无需安装依赖或构建。

## 功能

- 从 16 项日常行为中选择 1—3 项。
- 逐枚揭晓成就卡，支持跳过动画与降低动态效果。
- 在当前浏览器保存本地图鉴。
- 本地生成并保存 1080×1440 PNG 分享图片。

R / SR / SSR 仅为趣味卡面装饰，不代表真实稀有度或生活价值高低。本作品非小红书官方产品。

## 本地运行

将仓库文件放在静态服务器中，入口为 `index.html`。

```sh
python3 -m http.server 8000
```

浏览器访问 `http://localhost:8000`。

## GitHub Pages

上传后，在仓库的 **Settings → Pages** 选择 **Deploy from a branch**，选择包含这些文件的默认分支与 **/ (root)**，保存后等待 GitHub 完成部署。实际网址以 Pages 页面显示为准。

## 验证范围

已验证桌面 Chrome 下的手机尺寸模拟、1—3 项流程、全部 16 项映射、PNG 下载、存储异常降级和键盘操作。真实手机 Safari / Android Chrome 应在部署后补测。

图鉴只保存在当前浏览器；清除浏览器数据、换设备或换站点地址不会同步。

GitHub Pages 预览链接不能替代笔试要求的 REDcowork 发布与作品链接提交。
